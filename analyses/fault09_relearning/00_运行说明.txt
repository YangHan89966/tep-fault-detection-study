Fault 9 独立随机流复验｜本地运行

第一步
完整复制本目录到可写的新文件夹，例如 D:\F9。study_complete/ 保存五次训练重复的最终模型、校准结果和逐运行评价端点；原始轨迹另行归档。启动新模拟时使用独立工作目录。

在 Windows 上双击 RUN_FAULT9.cmd 即可。默认开 8 个进程，自动使用兼容的 Windows Python 或 WSL。先用一条不属于正式实验的 48 小时轨迹核对原引擎；核验通过后，接着原清单的第一个未完成样本继续。开发、校准、评价按顺序进行；请不要手工更改 locks 或已完成的原始数据。

环境
需要 64 位 CPython 3.12 与 NumPy 2.3.5。有合适环境不必安装。找不到时，先确保已装 Python 3.12，再双击 SETUP_ENV.cmd；这只准备套件文件夹内的虚拟环境，不改全局 Python，不启动科学运行。首次安装 NumPy 需要联网或已有对应的安装缓存。已有解释器不在默认路径时，可设置 F9_PYTHON 为其可执行文件完整路径。若本机原生环境未通过整轨核验，保留报错，改用已安装的 WSL 环境核验；不要跳过核验。

时间与空间
这里实测 8 个并行进程在 154 秒内完成 8 条正式开发轨迹。按这个速度，全部 2,719 条的模拟约 14.5 小时，另加拟合和统计；本机速度可能不同。建议工作盘留至少 5 GB 空间，接通电源并避免自动睡眠。

查看进度、指定目录或减少进程
在解压目录打开命令提示符。PowerShell 同样可使用下列 .\ 前缀：
  .\RUN_FAULT9.cmd --status
  .\RUN_FAULT9.cmd --workers 4 --work "D:\F9 work"
  .\RUN_FAULT9.cmd --work "D:\F9 work" --status
默认工作目录是套件中的 study；建议用 --work 指定新的模拟输出目录。本仓库不附带初始原始轨迹，首次运行从冻结清单开始。要把自己后来计算的进度移到另一块盘，请先停稳、完整复制整个工作目录，再将 --work 指到复制后的目录。后续查询或续跑始终使用同一目录。命令行调用可先设置 F9_NO_PAUSE=1，免去退出时按键。

WSL / Linux
在包含 RUN_WSL.sh 的解压目录执行：
  bash RUN_WSL.sh --status
  bash RUN_WSL.sh --workers 8 --work "/mnt/d/F9 work"
仅在缺少 NumPy 且已安装 Python 3.12（含 venv）时，先执行：
  bash RUN_WSL.sh --setup-runtime

暂停与继续
需要有序暂停时，在当前工作目录创建一个名为 STOP_AFTER_BATCH 的空文件（无扩展名）。程序完成正在运行的这一批后退出；模型拟合或最终汇总阶段可等当前步骤完成。要继续，删除该标记，再执行同一启动命令。临时断电或关闭窗口后也可重启：程序检查已完成文件的 SHA，仅重做中断项，并继续使用原先指定的随机键。

输出与归档
程序全部完成后，工作目录中的 F9_PAIRED_RELEARNING_COMPLETE.zip 为紧凑结果归档。未完成时，--status 只显示计数，不产生部分检出率。完整原始轨迹保留在 raw 目录，不包含在此紧凑结果包中。
