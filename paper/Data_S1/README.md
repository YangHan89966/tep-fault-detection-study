# Data S1 table numbers

These 83 CSVs retain the historical numbers used in the 7 November 2026 deposit. To find a table cited in the measurement–controller pairing manuscript, look up its submission or extended SI number in the [table crosswalk](../../measurement_pairing/tables/SI_table_crosswalk.csv). Each row gives a repository-relative CSV path for that edition.

For example, submission Table S1 is the [analysis timeline](../../measurement_pairing/tables/submission/Table_S01.csv). Submission Table S33 and extended Table S94 both correspond to historical [Table S67](Table_S67.csv). The [current table](../../measurement_pairing/tables/extended/Table_S94.csv) gives the updated section reference.

[index.csv](index.csv) and [README.txt](README.txt) describe the original numbering. They are also included in the historical Data S1 ZIP.
