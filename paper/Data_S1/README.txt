Data S1 - machine-readable tables

Supplementary Information to: Effects of monitoring statistic, projection direction and measurement–controller pairing on the detectability of Tennessee Eastman Faults 3, 9 and 15

Tables S1-S68 reproduce the tables of the Supplementary Information with the same numbers.
Tables D1-D15 are further tables cited as Data S1 in the Supplementary Information.
index.csv lists every file with its table title and table note.

Format: UTF-8 CSV, one file per table, values as printed (thousands separators, the minus sign U+2212,
intervals in square brackets). Header rows are reproduced as in the printed tables; a header cell spanning
several columns is written in its first column and the remaining columns are left empty.
