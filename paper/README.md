# Manuscript versions and supporting data

The [article repository](../README.md) accompanies *Measurement–controller pairing and fault detection in the Tennessee Eastman process*. Its supplementary information, tables and figure sources are in [Zenodo v1.1.0](https://doi.org/10.5281/zenodo.24519585).

The [7 November 2026 manuscript and Data S1](https://github.com/YangHan89966/tep-fault-detection-study/tree/study-archive-2026-11-25/paper) accompany the [earlier data release](https://doi.org/10.5281/zenodo.22084007). The historical directory includes instructions for restoring the original documents.
