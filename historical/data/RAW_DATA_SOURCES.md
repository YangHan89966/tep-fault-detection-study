# Raw-data sources

The historical study uses Rieth et al., *Additional Tennessee Eastman Process Simulation Data for Anomaly Detection Evaluation*, Harvard Dataverse, DOI `10.7910/DVN/6C3JR1`.

The four original RData files are not bundled in this code snapshot. `DATA_MANIFEST.csv` supplies their names, sizes and SHA-256 values. Obtain them from the source record and follow its redistribution terms. The repository supplies scripts for the documented derived-data workflows.

DV and R5 are separate generated-trajectory collections. Their archive records are `DV_RAW_ARCHIVE.json` and `R5_RAW_ARCHIVES.json`; they should not be substituted for the historical RData. Consult [input availability](../INPUT_AVAILABILITY.md) for required files and access status, and [licence scope](../LICENSE_SCOPE.md) before redistributing them.
