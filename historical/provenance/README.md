# Source and verification records

This directory records the identities of the scripts, configurations, numerical outputs and preparation steps associated with the repository.

`EXACT_EXECUTION_HASH_MANIFEST.csv` identifies the original machine-bound runners; `SUCCESS_REPORT_HASH_MANIFEST.csv` identifies their execution reports. Those original files are retained in the author archive because they include host-specific settings and are not portable scientific entry points.

Versioned JSON records describe the checks actually performed for the corresponding source or packaging version. File hashes, saved-result consistency checks, raw-data scoring and independent replication are different evidence levels. A successful file-integrity check is not a new scientific validation.

Historical records are retained without rewriting their outcomes or dates. The [reproduction guide](../REPRODUCTION_GUIDE.md) identifies current entry points.
