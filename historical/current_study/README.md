# Historical study components

Scientific code, fixed model states and saved results are organized by study: `dense_validation/`, `k_sensitivity/`, `f15_risktime/`, `r5_original_stage_sources/`, `r5_raw_identity/`, `r5_s21_s22/` and `reproduction/`. `plot_sources/` contains numerical figure inputs. The original study and table labels distinguish these evidence sets.

Use the [reproduction guide](../REPRODUCTION_GUIDE.md) and [method-to-code map](METHOD_TO_CODE_MAP.md) to locate entry points. The current paper documents are in `../../paper/`.
