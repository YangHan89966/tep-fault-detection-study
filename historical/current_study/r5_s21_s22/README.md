# Historical Supplementary Data S21 and S22

These modules accompanied historical manuscript v1.8.0. S21 contains all five downstream learning fits; S22 contains the fixed-alarm D2 endpoint analysis. Their original table and section numbers are historical labels.

The retained numerical arrays and result tables preserve the original scientific records. Original member identities are recorded in SOURCE_MEMBERS.json; the current FILES.json inventories describe this distribution. Documentation and transport metadata may differ from the original archive.

The S18 and S20 saved-result modules appear in `../k_sensitivity/` and `../f15_risktime/`. Original score paths for S22 are supplied separately in the S30 distribution identified by [the external input index](../EXTERNAL_INPUTS.csv). Raw trajectories are separate inputs described in [the root input guide](../../INPUT_AVAILABILITY.md).
