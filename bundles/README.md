# Scientific file bundles

Run `python unpack.py` from the repository root to restore the larger scientific files. The [bundle manifest](../BUNDLES.json) lists the parts, restored members, byte counts and SHA-256 hashes.

The Word manuscript, SI, Highlights and seven TIFF figures restored to [paper/](../paper/) belong to the 7 November 2026 historical snapshot. Use the [figure and analysis guide](../measurement_pairing/README.md) for the measurement–controller pairing study.
